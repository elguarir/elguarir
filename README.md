## 👨‍💻 About me

I'm a final-year Software Engineering student at **ENSIASD** and the main developer at **[Skwilti](https://skwilti.ma)**, a live EdTech platform. I took it from MVP to production and I own the backend, deployment and infrastructure.

These days I build **AI agents that run in production**: tool calling, RAG, and the backend work that keeps them reliable (queues, locks, idempotent webhooks).

- 🤖 Building a **WhatsApp AI agent** that runs Skwilti's support and sales in Arabic, Darija, French and English
- 📱 Shipping the **Skwilti mobile app** in React Native (Expo)
- ⚙️ Running my own **self-hosted infrastructure** with Docker, Coolify and Traefik
- 📍 Based in **Agadir, Morocco**
